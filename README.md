# Customer-Churn-Analysis
Customer Churn Analysis using Python, Pandas, Matplotlib and Seaborn

Objective
Analyze customer churn behavior and identify factors affecting customer retention.

Tools Used

Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

Key Findings

Overall churn rate is approximately 26.5%.
Month-to-Month customers have the highest churn rate.
Long-term contracts improve customer retention.
Customers with shorter tenure are more likely to churn.
Fiber Optic customers show higher churn compared to DSL users.
Business Recommendations
Promote long-term contracts.
Improve onboarding for new customers.
Monitor high-risk customer segments.
Encourage automatic payment methods.
